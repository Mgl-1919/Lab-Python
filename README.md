## Lab-Python
Création d'un projet type application basé en Python.

## Auteur
Miguel Andrade - Mgl-1919

## Technologies utilisées
- Python 3
- Tkinter (Interface Graphique)
- GitHub Desktop (gestion de code source)
- unittest (essais unitaires)

## Fonctionnalités
- Gestion des clients (créer, modifier et supprimer)
- Catalogue de films avec catégories et acteurs
- Connexion des employés avec deux niveaux d'accès (TOTAL/LECTURE)
- Essais unitaires automatisés

## Comment exécuter
1. Cloner le repository
2. Ouvrir avec PyCharm
3. exécuter App_RAC.py

## Structure du projet
- models.py --> Classe du domaine
- App_RAC.py --> Interface graphique
- Test_RAC.py --> Essais unitaires
- Diagramme_des_classes.puml --> Diagramme des classes
